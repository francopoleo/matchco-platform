# Guia de Uso: Materiais de Marketing & Vendas

**Para:** Sales team, Marketing, Executivos  
**Objetivo:** Saber qual documento usar em cada situação

---

## Mapa de Documentos

### 📌 Nível 1: Primeira Impressão (30 segundos - 2 minutos)

#### **EXECUTIVE_ONEPAGER.md** ← COMECE AQUI PARA STAKEHOLDERS
- **Quando usar:** Reunião com CFO, CEO, COO que não conhece Talk
- **Formato:** 1 página, 3 números principais, ROI claro
- **Tempo:** 2 minutos de leitura
- **Entregável:** PDF impresso ou slide único

**Exemplo de uso:**
```
Cenário: Você tem 15 min com CFO
├─ Minuto 1-2: Problema (fragmentação de comunicação)
├─ Minuto 2-3: Solução (Talk unifica)
├─ Minuto 3-4: 3 números (tempo, conformidade, ROI)
├─ Minuto 4-5: Case similar (hospital X)
└─ Minuto 5+: Próximos passos (demo/piloto)

Resultado: CFO entende ROI, aprova continuação
```

---

### 📊 Nível 2: Detalhes Técnicos (5-10 minutos)

#### **ABOUT_TALK_COMPLETE.md** ← PARA COMPREENSÃO PROFUNDA
- **Quando usar:** Gerente operacional precisa entender o que Talk faz
- **Formato:** Página de "Sobre", com aplicações práticas por setor
- **Tempo:** 10-15 minutos de leitura
- **Entregável:** Enviar via email, linkar na landing page

**Exemplo de uso:**
```
Cenário: COO lê sobre Talk, quer entender como funciona
├─ Lê: "O que é Talk"
├─ Entende: Os 3 pilares (Cursos, Feed, Wiki)
├─ Vê exemplo de seu setor
├─ Descobre: "Ah, resolveria nosso problema de protocolo novo"
└─ Clica: "Quer um demo?"

Resultado: COO está convencido, quer ver ao vivo
```

---

### 🎯 Nível 3: Estratégia de Vendas (20-90 minutos)

#### **SALES_PLAYBOOK.md** ← PARA TEAM DE VENDAS E PARTNERS
- **Quando usar:** Seu sales team precisa de estrutura completa
- **Formato:** Playbook completo (pitch, objections, ROI, timeline)
- **Tempo:** Estudo de 1-2h, depois aplicação
- **Entregável:** Treinar equipe, criar collateral customizado

**Exemplo de uso:**
```
Cenário: Sales rep tem reunião com gerente de hospital
├─ Usa: Elevator Pitch (30 seg)
├─ Se interessou: Vai para Problema 1-3
├─ Se pegou: Mostra ROI customizado (Saúde)
├─ Se duvidoso: Usa Objection Handling
├─ Se quer ver: Oferece demo ou piloto
└─ Se quer desacelerar: Manda one-pager

Resultado: Pipeline avança para próximo estágio
```

---

### 🚀 Nível 4: Implementação Prática (30-60 minutos)

#### **PRACTICAL_WORKFLOWS.md** ← PARA OPERAÇÕES E IMPLEMENTAÇÃO
- **Quando usar:** Já convenceu o cliente, agora mostra como funciona
- **Formato:** 3 fluxos detalhados passo-a-passo (Saúde, Seguros, Manufatura)
- **Tempo:** 15-20 minutos de leitura (antes de demo)
- **Entregável:** Compartilhar antes de demo, usar como script

**Exemplo de uso:**
```
Cenário: Cliente quer ver demo
├─ Você prepara: qual fluxo é relevante?
├─ Se Saúde: "Vou mostrar como protocolo novo é publicado"
├─ Se Seguros: "Vou mostrar como novo produto é treinado"
├─ Se Manufatura: "Vou mostrar como nova linha é operacional"
├─ Durante demo: Segue o fluxo (cliente vê exatamente seu caso)
└─ Depois de demo: "Viu? Aqui está passo-a-passo por escrito"

Resultado: Cliente sai da demo com documento praticamente pronto
```

## Fluxo de Vendas Sugerido

```
STAGE 1: Awareness (Prospect não sabe Talk)
├─ Artefato: Landing Page + LinkedIn post
├─ Objetivo: Criar interesse
└─ Next: Agendar conversa

STAGE 2: Discovery (Entender dor)
├─ Artefato: EXECUTIVE_ONEPAGER (15 min)
├─ Conversa: "Qual é seu maior problema?"
└─ Next: Se pegou, vai para Stage 3

STAGE 3: Education (Mostrar solução)
├─ Artefato: ABOUT_TALK_COMPLETE (email ou leitura)
├─ Conversa: "Talk resolve assim..."
└─ Next: Se interessado, vai para Stage 4

STAGE 4: Validation (Ver na prática)
├─ Artefato: PRACTICAL_WORKFLOWS (antes de demo)
├─ Demo: Ao vivo, seguindo fluxo do cliente
└─ Next: Se convencido, vai para Stage 5

STAGE 5: Decision (Comitê aprova)
├─ Artefato: SALES_PLAYBOOK (ROI customizado) + EXECUTIVE_ONEPAGER
├─ Presentação: C-level vê números
└─ Next: Se aprova, vai para Stage 6

STAGE 6: Piloto (Provar valor)
├─ Artefato: PRACTICAL_WORKFLOWS (guia de implementação)
├─ Implementação: 30 dias, um problema específico
└─ Next: Se sucesso, vai para Stage 7

STAGE 7: Contrato (Expandir)
├─ Artefato: Proposta customizada
├─ Negociação: Preço, SLA, timeline
└─ Result: Deal fechado
```

## Como Customizar para Seu Prospect

```

Aqui está um case de 3 números:
├─ Antes: [tempo/aderência/custo]
├─ Depois: [melhoria]
└─ ROI: [número]

Você tem 15 min essa semana para ver ao vivo?

[Link para agendar]

Abs,
[Seu nome]
```

### Template: Pitch de 30 Segundos

```
"[Nome], percebi que vocês comunicam mudanças de [processo] para [número] pessoas.
Talk faz isso em [tempo] ao invés de [tempo antigo].
Resultado: [pessoa-chave] aprova [mudança] rápido, sem retrabalho.
Quer ver como funciona em 15 min?"
```

### Template: Apresentação de 20 Min

```
Slide 1:  [Seu nome] + Talk
Slide 2:  O problema (seu contexto)
Slide 3:  A solução (Talk em 60 seg)
```

## Perguntas Frequentes

### P: Qual documento começo?
**R:** Depende do prospect:
- CEO/CFO → ONE_PAGER
- COO/Ops → ABOUT
- Demo preparada → WORKFLOWS
- Pipeline construir → SALES_PLAYBOOK

### P: Posso compartilhar antes da demo?
**R:** Sim!
- ONE_PAGER via email (depois de conversa inicial)
- ABOUT + WORKFLOWS (24h antes da demo)
- SALES_PLAYBOOK (só com time interno)

### P: Como customizar para meu setor?
**R:** Veja "Variações por Setor" acima. Ou:
1. Leia SALES_PLAYBOOK (setor específico)
2. Customize números (seu hospital/corretora/fábrica)
3. Adicione case local (se tiver)
4. Customize ROI (seu negócio)

### P: E se prospect quer detalhes técnicos?
**R:** 
- Segurança → ABOUT (seção Conformidade)
- Integrações → SALES_PLAYBOOK (ROI + tech)
- SLA/Uptime → SALES_PLAYBOOK (seção Support)

### P: Como rastrear que doc foi lido?
**R:**
- Email com link trackado → Google Analytics
- Slack/Teams → vê reação
- Envio de doc antes de call → pergunta "leu?"

## Feedback Loop

Após cada venda/não-venda:

```
Compile:
├─ Qual doc foi mais útil?
├─ Qual objection apareceu?
├─ Qual métrica convenceu?
└─ O que faltou?

Update:
├─ Se objection nova → adiciona em SALES_PLAYBOOK
├─ Se caso novo → cria variant de WORKFLOWS
├─ Se métrica falhou → ajusta ONE_PAGER
└─ Mensalmente: revisa todos docs
```

## Conclusão

**Regra de Ouro:** Certo documento na hora certa no prospect certo = venda.

- **Rápido:** ONE_PAGER (CFO não tem tempo)
- **Detalhado:** ABOUT (Ops quer entender)
- **Prático:** WORKFLOWS (Demo precisa de script)
- **Estratégico:** SALES_PLAYBOOK (Time precisa de estrutura)

Use todos. Customize conforme prospect. Track resultados. Melhore continuamente.
