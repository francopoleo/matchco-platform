Como Usar a Documentação

Na Web (Recomendado)

  1. Acesse: https://direct.ddns.net/console/documentacao/
  2. Clique em uma categoria
  3. Clique em um documento
  4. Leia o markdown renderizado
  5. Use a sidebar para navegar; após atualizar a página, ela mantém o estado correto conforme o tamanho da tela
  6. Baixe o .html original se precisar

Localmente (Terminal)

# Ler um documento
cat /Users/franco/Dev/matchco/matchco/docs/help/html/01_ADMIN_SETUP_QUICK_REFERENCE.html

# Listar todos
ls -1 /Users/franco/Dev/matchco/matchco/docs/help/html/

# Procurar por palavra-chave
grep -r "multi-tenant" /Users/franco/Dev/matchco/matchco/docs/
grep -r "troubleshooting" /Users/franco/Dev/matchco/matchco/docs/

Em um Editor (VS Code, etc)

  1. Abra a pasta: /Users/franco/Dev/matchco/matchco/docs/
  2. Procure por 01_, 02_, etc
  3. Use Ctrl+Shift+P > "Markdown Preview"
  4. Veja renderizado em tempo real

Dicas de Navegação

Na Web

  • Dark mode: Automático com preferência do sistema
  • Sidebar pegajosa: Navega junto enquanto você scroll
  • Breadcrumb: Sempre sabe aonde você está
  • Download .html: Botão no final de cada documento

Em Markdown Puro

  • Abra em editor favorito (VS Code, Vim, etc)
  • Procure com Ctrl+F
  • Copy-cola de código direto
  • Funciona offline

Não encontrou?

  1. Procure em INDEX.html — tem tudo indexado
  2. Procure em README.html — talvez tenha um link
  3. Procure no GitHub — grep em todo docs/
  4. Pergunte no Slack — alguém da equipe vai saber
