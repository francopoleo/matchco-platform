Shopping Center

Visão Geral

Shopping center com múltiplas lojas, varejo, e diferentes segmentos (alimentação, moda, eletrônicos, etc).

Características Específicas

  • Estrutura: Múltiplas lojas independentes dentro de um shopping
  • Funções Típicas: Atendente de caixa, repositor, vendedor, gerente de loja
  • Segmentos: Alimentação, moda, beleza, eletrônicos, supermercado
  • Rotatividade: Alta (retail típico)
  • Modelo de Negócio: RH central do shopping coordena com gerentes de loja

Funções Padrão

Atendente de caixa
Repositor
Vendedor
Gerente de loja
Assistente de atendimento
Supervisor

Segmentos de Experiência

  • Alimentação / Cafeteria
  • Moda / Roupas
  • Calçados
  • Beleza / Cosméticos
  • Eletrônicos
  • Supermercado
  • Loja de departamentos
  • Serviços

Fluxo de Setup

  1. Criar Organization
python manage.py shell

from configuration.models import Organization, Domain

org = Organization.objects.create(
    name='Shopping XYZ SA',
    slug='shopping-xyz',
    active=True,
)

Domain.objects.create(
    domain='shopping-xyz.br.matchco.app',
    tenant=org,
    is_primary=True,
)
  1. Importar Lojas (do CSV)
# Preparar stores.csv com colunas: Name, Latitude, Longitude, Segment
# Exemplos:
# Loja A - Centro,-23.564,-46.652,Moda
# Loja B - Zona Sul,-23.560,-46.658,Alimentação

  1. Criar Usuários - Admin do shopping: acesso completo ao console - Gerentes de loja: acesso limitado a suas lojas

  2. Criar QR Codes - Um QR por loja - Modo MATCH, com uma entrada permanente por unidade

Relatórios Importantes

  • Conversão por unidade (QR → Perfil → oportunidade → interesse → Match)
  • Necessidades abertas vs pessoas elegíveis
  • Melhor segmento de origem de candidatos
  • Velocidade média de contratação por loja

Hospital

Visão Geral

Hospital com múltiplos departamentos e especialidades.

Características Específicas

  • Estrutura: Departamentos/unidades (Emergência, UTI, Cirurgia, etc)
  • Funções Típicas: Enfermeiro, técnico de enfermagem, médico, assistente administrativo
  • Especialidade: Saúde; exigências regulatórias (LGPD para dados sensíveis)
  • Disponibilidade: Turnos 24h (manhã, tarde, noite)
  • Rotatividade: Média a baixa (contratos mais estruturados)
  • Modelo de Negócio: RH central coordena contratações para departamentos

Técnico de Enfermagem
Médico(a)
Assistente Administrativo
Recepcionista
Nutricionista
Psicólogo(a)
Farmacêutico(a)

Segmentos de Experiência

  • Emergência
  • Internação
  • UTI
  • Cirurgia
  • Pediatria
  • Maternidade
  • Laboratório
  • Farmácia

    slug='hospital-central',

Domain.objects.create(
    domain='hospital-central.br.matchco.app',
    tenant=org,
    is_primary=True,
)
  1. Importar Departamentos (como "lojas" no sistema)
# Cada departamento é uma unidade com suas próprias necessidades
# Departamentos: Emergência, UTI, Cirurgia, Pediatria, etc

  1. Criar Usuários - Admin do hospital: acesso completo - Chefes de departamento: acesso limitado ao departamento - Gerentes de RH: visão consolidada

  2. Configurações Especiais - Turnos: Manhã, Tarde, Noite (disponibilidade 24h) - Compliance: Exigir validação de certificações de saúde quando aplicável - Privacidade: Dados de saúde com criptografia reforçada

Relatórios Importantes

  • Necessidades por departamento e função canônica
  • Turnos mais difíceis de preencher
  • Candidatos com certificações relevantes
  • Tempo médio de contratação por especialidade
  • Conformidade com regulamentações

Farmácia / Drogaria

Visão Geral

Rede de farmácias com múltiplas filiais/unidades.

Características Específicas

  • Estrutura: Filiais / unidades espalhadas geograficamente
  • Funções Típicas: Atendente de caixa, balconista, farmacêutico, auxiliar
  • Modelo: Franquia ou rede corporativa
  • Rotatividade: Alta (varejo farmacêutico)
  • Competência: Conhecimento de produtos, conselhos de saúde
  • Modelo de Negócio: Franquias ou rede central coordena

Funções Padrão

Atendente de Caixa
Balconista de Manipulação
Farmacêutico(a)
Auxiliar de Farmácia
Gerente de Filial
Operador de Logística

Segmentos de Experiência

  • Atendimento ao público
  • Medicamentos genéricos
  • Medicamentos controlados (exigência legal)
  • Cosméticos e higiene
  • Insumos para saúde
  • Manipulação de fórmulas

Troubleshooting por Setor

Shopping

  • Problema: Poucos interesses para uma necessidade de alto giro Solução: Implementar limite de exposição / rotação de candidatos

  • Problema: Candidatos cadastram em múltiplas lojas do mesmo shopping simultaneamente Solução: Explicar o sistema de pool; incentivar consentimento único

Hospital

  • Problema: Difícil encontrar profissionais com certificação válida Solução: Integrar validação com COREN/CREMESP; mostrar status de certificação

  • Problema: Turno de noite com pouca cobertura Solução: Marcar preferência de turno como obrigatória; oferecer incentivos

Farmácia

  • Problema: Rotatividade muito alta; candidatos saem rápido Solução: Implementar feedback pós-contratação; identificar padrões

  • Problema: Unidades distantes com pouca cobertura Solução: revisar território, disponibilidade e prazo da rodada; sem expor endereço completo
