# Documentação legada

Esta pasta preserva decisões, planos, guias e arquivos antigos apenas para
consulta histórica. Não use estes documentos para criar novas funcionalidades.

Para o estado atual, consulte [`../atual/`](../atual/).

- `desenvolvimento/`: planos técnicos e referências antigas.
- `arquivo/`: materiais arquivados, versões anteriores e artefatos.
