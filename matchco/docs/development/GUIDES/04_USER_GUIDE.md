# 👥 User Guide - For Enterprise Customers

**For:** Students, Managers, Administrators  
**Time:** 10 minutes (first time)

---

## 🎓 For Students

### Getting Started

1. **Login to Portal**
   - Visit: `https://yourcompany.matchco.io`
   - Email: Your company email
   - Password: Create at login

2. **Enroll in a Course**
   - Dashboard → "Browse Courses"
   - Click "Enroll" on course
   - Start learning immediately

3. **Complete a Course**
   - Read content (must scroll 100%)
   - Watch videos (95% required)
   - Take quiz (pass score: 70%)
   - See certificate upon completion

### Features

**📚 Course Dashboard**
- View all enrolled courses
- See progress % per course
- Track time spent
- Access certificates

**📹 Video Player**
- Play/Pause/Speed controls
- Resume where you left off
- See time remaining
- Track viewing progress

**📝 Quizzes**
- Multiple choice questions
- Instant feedback
- Retake if needed (manager-dependent)
- View score report

**📄 Content Sharing**
- Manager shares packages with you
- Access shared courses directly
- Download certificates
- Track expiration dates

**📊 Progress**
- See % completion
- View required steps
- Time-to-complete estimate
- Status: Not Started → In Progress → Complete

### How to Get Help

- **Chat support:** Click help icon (bottom right)
- **Email:** support@matchco.io
- **FAQ:** In profile menu
- **Manager:** Contact your training manager

## 👔 For Managers

### Managing Courses

**Create Course**
1. Console → "New Course"
2. Add title, description, banner
3. Add modules (max 10)
4. Add content (text, video, quiz)
5. Publish when ready

**Edit Course**
1. Console → Course list
2. Click course name
3. Edit any section
4. Save changes
5. Changes apply immediately

**Share Course**
1. Console → "Share"
2. Select course/module
3. Choose recipients (users or groups)
4. Set expiration date (optional)
5. Send notifications

### Analytics & Reports

**View Progress**
1. Console → "Analytics"
2. Filter by course/group
3. See completion % per person
4. Download as PDF/CSV

**Export Reports**
1. Console → "Reports"
2. Select date range
3. Choose report type:
   - Completion Report
   - Certificate Report
   - Time Spent Report
4. Download Excel file

**Generate Certificates**
1. Console → "Certificates"
2. Select course
3. Click "Generate All"
4. Send to users via email

### User Management

**Add Users**
1. Console → "Users"
2. Click "Add User"
3. Enter email
4. Set role (Student/Manager/Admin)
5. Send invite

**Manage Groups**
1. Console → "Groups"
2. Create group by department
3. Add users to group
4. Assign courses to entire group

**Reset Passwords**
1. User profile → "Reset Password"
2. Link sent to email
3. User creates new password

## 🔒 Security Best Practices

### For All Users

✅ **DO:**
- Use strong passwords (12+ chars)
- Enable 2FA if available
- Log out when done
- Report suspicious activity

❌ **DON'T:**
- Share login credentials
- Use public WiFi for sensitive data
- Leave browser open unattended
- Click suspicious links

### Password Requirements

- Minimum 12 characters
- Mix uppercase, lowercase, numbers
- At least one special character (!@#$%)
- Change every 90 days
- Cannot reuse last 5 passwords

## ❓ Frequently Asked Questions

**Q: Can I retake a quiz?**
A: Yes, if your manager allows it. Click "Retake Quiz" on your dashboard.

**Q: How long do certificates last?**
A: Varies by course. Check certificate details or ask your manager.

**Q: Can I download course content?**
A: Only PDFs and documents. Videos are not downloadable (by design).

**Q: How do I get a certificate?**
A: Complete all course requirements. Certificate auto-generates and emails to you.

**Q: What if I see an error?**
A: Try clearing browser cache. If persists, contact support.

**Q: Can managers see my progress?**
A: Yes, only managers assigned to your courses can see your progress.

**Q: Do I lose progress if I pause?**
A: No, your progress is saved. Resume anytime.

**Q: What video formats are supported?**
A: MP4, WebM, M3U8 (HLS). Works on mobile and desktop.
