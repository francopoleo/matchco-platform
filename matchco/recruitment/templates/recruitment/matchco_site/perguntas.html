01{% trans "O que é o MatchCo?" %}

{% trans "MatchCo é uma infraestrutura de conexão entre pessoas, organizações e necessidades reais, começando pela empregabilidade." %}

{% trans "A pessoa cria um Perfil sem currículo. Quando existe uma necessidade real de trabalho, essa necessidade pode chegar a pessoas que conseguem realizá-la. A pessoa decide. A loja também. Interesse dos dois lados é Match." %}

{% trans "Depois do primeiro contato, a mesma relação pode continuar em cursos, certificações, Feed, Wiki e novas oportunidades — sempre com o contexto e a decisão de cada participante." %}

{% trans "O modelo também pode ser usado por um Shopping, fabricante, distribuidor ou rede varejista para organizar sua rede de lojas e profissionais. A pessoa pode participar gratuitamente; o programa é financiado pela organização que se beneficia da rede preparada." %}

02{% trans "É um portal de vagas?" %}

{% trans "Não." %}

{% trans "No MatchCo não existe catálogo de vagas para procurar, “ver todas as oportunidades” ou candidatura em massa." %}

03{% trans "É um banco de candidatos?" %}

{% trans "Não." %}

{% trans "A loja não pesquisa uma base de pessoas. Parte de uma necessidade real e vê apenas quem decidiu demonstrar interesse naquela relação." %}

04{% trans "Por que não existe currículo?" %}

{% trans "Porque o MatchCo pergunta primeiro o que realmente importa para uma possibilidade de trabalho." %}

{% trans "O Perfil substitui o currículo nessa relação inicial." %}

05{% trans "O que significa “O emprego encontra você”?" %}

{% trans "Significa que a pessoa não precisa monitorar uma lista de vagas dentro do MatchCo." %}

{% trans "Quando existe uma necessidade real que ela pode realizar, essa oportunidade pode chegar até ela." %}

{% trans "A decisão continua sendo da pessoa." %}

{% trans "Não é garantia de emprego, Match ou resultado imediato." %}

06{% trans "O Shopping vira recrutador?" %}

{% trans "Não." %}

{% trans "O Shopping abre e legitima o território." %}

{% trans "MatchCo instala e opera." %}

{% trans "A loja continua dona da necessidade e da contratação." %}

07{% trans "O Shopping vê os candidatos?" %}

{% trans "Não recebe uma base nominal de pessoas para pesquisar." %}

{% trans "Dados individuais não se tornam um ativo do Shopping." %}

08{% trans "“TRABALHE AQUI” significa que aquela loja está contratando agora?" %}

{% trans "Não." %}

{% trans "É um convite permanente para entrar na infraestrutura MatchCo." %}

{% trans "O Ponto pode continuar instalado mesmo quando não existe uma vaga ativa naquela loja." %}

09{% trans "Quem entra pelo Ponto de uma loja pertence àquela loja?" %}

{% trans "Não." %}

{% trans "O Ponto pode registrar por onde a pessoa entrou." %}

{% trans "Isso não cria propriedade, reserva ou prioridade." %}

10{% trans "O MatchCo usa geolocalização da pessoa?" %}

{% trans "O modelo não precisa acompanhar a localização da pessoa em tempo real para entender onde ela consegue trabalhar." %}

{% trans "A própria pessoa informa os territórios em que consegue trabalhar." %}

11{% trans "Primeiro emprego funciona?" %}

{% trans "Sim." %}

{% trans "Experiência formal anterior não é requisito para criar um Perfil." %}

{% trans "Uma necessidade específica pode ter critérios próprios, mas primeiro emprego é uma condição legítima dentro do MatchCo." %}

12{% trans "Existe ranking de candidatos?" %}

{% trans "Não." %}

{% trans "Não existe Top 10, score, percentual de compatibilidade ou “melhor candidato”." %}

{% trans "O MatchCo organiza uma relação possível." %}

{% trans "As pessoas decidem." %}

13{% trans "A loja recebe o contato da pessoa quando ela demonstra interesse?" %}

{% trans "Ainda não." %}

{% trans "Primeiro a pessoa demonstra interesse." %}

{% trans "Depois a loja decide se também quer continuar." %}

{% trans "Só com interesse dos dois lados o contato direto pode ser habilitado." %}

14{% trans "Match significa contratação?" %}

{% trans "Não." %}

{% trans "Match é interesse dos dois lados suficiente para começar uma conversa direta." %}

{% trans "Entrevista, avaliação, oferta e contratação continuam pertencendo à pessoa e ao empregador." %}

15{% trans "O MatchCo substitui o ATS da empresa?" %}

{% trans "Não." %}

{% trans "O MatchCo atua antes do processo seletivo tradicional: entrada, Perfil, necessidade real, interesse e Match." %}

{% trans "Depois do contato, o processo da empresa continua onde ela já conduz entrevista, avaliação, oferta e contratação." %}

16{% trans "A pessoa paga?" %}

{% trans "Não." %}

{% trans "Criar e manter o Perfil, receber uma oportunidade, demonstrar interesse e chegar a um Match são gratuitos para a pessoa." %}
