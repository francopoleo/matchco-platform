## 📊 Análise Comparativa: Modelo de Preço

### Opção 1: Compra por Curso (Pay-Per-Course)

**Modelo:**
- Cada curso vendido individualmente
- Preço: R$ 29-99 por curso
- Acesso permanente após compra

**Vantagens:**
- Entrada baixa (usuário testa um curso)
- Ideal para aprendizado pontual

**Desvantagens:**
- Fragmentação (usuário compra 1 curso, depois abandona)
- Conversão baixa (usuário hesita em comprometer)
- Ticket pequeno (R$ 29-99)
- Sem previsibilidade de receita
- Abandono rápido (usa curso, sai)

**Aplicação:** ❌ Não recomendado para varejo/empresas

---

### Opção 2: Subscription Mensal (Acesso Ilimitado)

**Modelo:**
- R$ 29-49/mês por usuário (por loja)
- Acesso a catálogo completo
- Trilhas recomendadas
- Certificados inclusos

**Vantagens:**
- ✅ Alinhado com modelo Talk Recruitment (já pagam mensalidade)
- ✅ Previsibilidade de receita
- ✅ Incentiva consumo contínuo
- ✅ Bundling com Recruitment = penetração rápida
- ✅ Ticket recorrente (R$ 29-49/usuário/mês)
- ✅ LTV muito maior (retenção 6-12 meses)

**Desvantagens:**
- Requer educação sobre valor
- Churn se não houver engajamento
- Custo de produção de cursos

**Aplicação:** ✅ **RECOMENDADO**

---

### Opção 3: Híbrido (Freemium + Premium)

**Modelo:**
- Primeiros 3 cursos gratuitos (onboarding)
- Cursos avançados em subscription (R$ 39/mês)
- Certificação premium paga

**Vantagens:**
- Reduz fricção inicial
- Viraliza pelo "grátis"
- Converte via FOMO

**Desvantagens:**
- Mais complexo de gerenciar
- Mix de modelos confunde vendas

**Aplicação:** ⚠️ Considerar em Y2

---

## 💡 Recomendação Final

**Modelo: Subscription Mensal (Opção 2)**

**Rationale:**
1. **PMEs/Varejo já pagam mensalidade** por Talk Recruitment (R$ 99/loja/mês)
2. **Bundle:** Talk Recruitment + Cursos = R$ 129/loja/mês (vs R$ 99)
3. **Empresa economiza** em LMS separado + recrutamento
4. **Urgência educacional** no varejo é alta (turnover 80%+)
5. **Receita recorrente** é mais previsível (SaaS)

## 🏗️ Arquitetura Técnica: Cursos

### Database Models

```python
class Course(models.Model):
    title = CharField()
    description = TextField()
    duration_minutes = IntegerField()
    tier = CharField(choices=['mandatario', 'vendas', 'desenvolvimento'])
    status = CharField(choices=['draft', 'published', 'archived'])
    price_standalone = DecimalField(null=True)  # R$ 39 se vendido isolado
    requires_certification = BooleanField()
    
    # Conteúdo
    modules = ForeignKey('Module')  # 3-5 módulos por curso
    
    # Engajamento
    created_at = DateTimeField(auto_now_add=True)
    
    # Analytics
    views = IntegerField(default=0)
    completion_rate = DecimalField(default=0)

class CourseEnrollment(models.Model):
    user = ForeignKey(User)
    course = ForeignKey(Course)
    enrollment_type = CharField(choices=['mandatory', 'recommended', 'optional'])
    enrolled_at = DateTimeField(auto_now_add=True)
    completed_at = DateTimeField(null=True)
    completion_percentage = DecimalField(default=0)
    score = IntegerField(null=True)  # Para cursos com quiz
    certificate_issued = BooleanField(default=False)
    
class Certificate(models.Model):
    user = ForeignKey(User)
    course = ForeignKey(Course)
    issued_date = DateTimeField(auto_now_add=True)
    expires_at = DateTimeField(null=True)  # Certificações têm validade
    verification_token = CharField()  # Para compartilhamento verificável
```
