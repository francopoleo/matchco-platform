# Talk Learning 1.0.0.0

**Status:** baseline funcional para início da demonstração enterprise  
**Data:** 2026-07-24

## O que esta versão preserva

- Shell global com navbar, sidebar, tema claro/escuro e avatar do usuário.
- Padrão Flowbite para páginas de cursos, feed, wiki, perfil e console.
- Cursos com cards/lista, progresso, módulos e modo de estudo.
- Feed como comunicação rápida e Wiki como conhecimento permanente.
- Audiência por organização, empresa, unidade de negócio, unidade operacional, canal e função.
- Simulação de audiência e contagem de usuários impactados.
- Gestão de vínculos de usuários e permissões por escopo.
- Configurações de conta dentro do perfil.

## Critério de release

Este release é um ponto de restauração antes da criação da massa hospitalar. O seed hospitalar deve ser repetível, identificado por slugs próprios e nunca misturado aos dados de demonstração genéricos.

## Próximo marco

`1.1.0.0` — demonstração Hospital Generative, com reset explícito da base, administrador preservado, estrutura organizacional, usuários, audiência, cursos, feeds, wikis e conteúdos operacionais.
